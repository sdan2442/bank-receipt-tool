# 银行回单拆分与重命名工具 v0.3.10

本程序适用于 Windows 10/11 64 位，所有 PDF、图片、OCR 文本、处理记录和日志均在本机保存，不调用在线 OCR、云端 API 或远程大模型。

**Windows 离线包已包含 Python 运行环境和四个 OCR 模型。使用者无需安装 Python，也无需另外下载模型，首次运行即可离线使用。**

## 启动前

1. 将下载的 ZIP **完整解压**到本地磁盘，例如 `C:\BankReceiptTool_v0_3_10`。
2. 不要只复制或移动 `银行回单工具.exe`；同目录的 `_internal`、本地 OCR 模型和运行库缺一不可。
3. 请使用所有父级目录均为英文或数字的路径，避免推理库无法打开本地模型。
4. 首次运行若 Windows SmartScreen 提示“未知发布者”，请先核对发布页面给出的 SHA-256 校验值；本版本未购买代码签名证书。

## 基本使用

1. 双击 `银行回单工具.exe`。
2. 点击“选择文件”或“选择输入文件夹”，在清单中勾选需要处理的项目。
3. 默认输出到“桌面\银行回单处理结果”，也可在界面另选目录。程序保留原文件。
4. 选择 OCR 模式：
   - **高精度**：server 检测 + server 识别，速度较慢，适合正式处理。
   - **均衡**：mobile 检测 + server 识别，通常更适合普通 CPU。
   - **快速（默认）**：mobile 检测 + mobile 识别，OCR 成功结果均进入人工复核。
5. 点击“开始处理”。程序按页完成拆分、方向校正、OCR、字段提取和保存，并逐页更新进度。
6. 双击待复核记录，核对字段和 OCR 全文，修改后点击“确认并保存”。批量 OCR 期间，已处理完的页面也能复核并保存。

默认文件名为：

`交易时间中的日期_付款人户名_交易金额.pdf`

例如：`2026-09-08_上海某某贸易有限公司_12500.00.pdf`。

## 发票识别

可将电子发票、常见增值税发票和银行回单放入同一批任务。发票文件名使用 `发票号_购买方_价税合计小写金额_开票日期.pdf`。例如 `25000000000000000001_示例采购有限公司_113.00_2025-01-07.pdf`。

在复核窗口核对发票号、购买方、价税合计（小写）和开票日期。若同一页扫描了多张发票，可在复核窗口手动画框拆分。

本版为公开测试版。上下布局的发票、被 OCR 拆成单字的购买方标签可能导致购买方留空，金额及开票日期也可能漏识别。请结合原图逐项核对，不要直接依赖自动文件名。

## 暂停、停止与恢复

- “暂停”可在当前程序中继续。
- “停止并保存进度”会在安全位置写入断点，下次可从未完成页继续。
- 异常退出或电脑关机后，重新启动程序，把输出目录指向原处理结果目录，再点击“加载历史任务 / 继续复核”。
- 也可选择指定页码重新处理，例如 `13-32` 或 `1,3,8-10`。

## 输出目录

```text
输出目录/
├─ success/                  已确认成功的 PDF
├─ review/                   待人工复核的 PDF 和本地复核资料
├─ failed/                   处理失败但保留内容的项目
├─ logs/                     已脱敏错误日志与本地 OCR 审计记录
├─ .jobs/                    断点和历史任务记录
└─ processing_results.xlsx   处理结果表
```

程序不会上传上述内容。分享或提交结果前，仍应由使用者检查 PDF、Excel、`review`、`logs` 和 `.jobs` 是否包含业务敏感信息。

## 承兑汇票与多张回单

- 检测到多页承兑汇票时，会先进入人工勾选合并流程；合并顺序按勾选先后排列。
- 未知类型也可在主界面点击“手动合并页面 / 排序”，预览后按目标页序逐个勾选，再点击“合并并进入人工核对”。
- 一页多张回单只有在裁切边界和关键字段验证可靠时才自动拆分。
- 批次结束后，在复核窗口点击“手动拆分”。在空白处拖动或使用“新增裁片”画框。点选现有框后，拖边或角的圆点调整大小，拖框内移动。重叠时可从列表选择具体裁片。点击“生成裁片”后，每份 PDF 保留各自框内的内容，完整页面也保留。

## 常见问题

- **程序暂时“未响应”**：CPU 本地 OCR 处理高分辨率页面时可能耗时较长，请观察页级状态；高精度模式通常最慢。
- **OCR 失败或 DLL 加载失败**：安装 Microsoft Visual C++ 2015–2022 x64 运行库，并确认杀毒软件未隔离 `_internal` 中的文件。
- **预览为空**：确认 `review` 下的 PDF、JSON 和 `.previews` 未被手工移动；可从原输出目录重新加载历史任务。
- **误裁切或字段不准确**：保留整页并进入人工复核；不要删除原文件。复杂表格、印章遮挡、低清扫描和手写内容仍可能需要人工判断。
- **首次启动是否需要联网**：不需要。四套 PP-OCRv5 本地模型和运行库已经随 Windows 运行包提供。

## 数据安全提醒

- 不要把真实银行回单、输出目录、日志、OCR 审计 JSON 或处理结果表提交到 GitHub、网盘公开链接或问题反馈页面。
- 对外反馈问题时只使用脱敏或合成样例。
- 程序默认不覆盖原文件；写出结果时先生成临时文件，再原子化改名。
